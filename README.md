# Michigan Premier mobile prototype

This student project is a front-end prototype for a premium Michigan Football game-day experience. It includes:

- digital passes for the primary ticket holder and guests;
- automatic step-free navigation for a guest with accessibility accommodations;
- stadium routes to the user's seat and pregame field access;
- live crowd guidance and an escort request flow;
- a functional concierge chat;
- saved accessibility preferences;
- a direct game-day concierge chat shortcut;
- Headless UI-inspired tabs, switches, and modal dialog behavior; and
- WCAG 2.1 AA-focused keyboard, contrast, focus, and text-size support.

## Run the app

Open `index.html` in a browser, or serve this directory locally:

```bash
python -m http.server 8000 --directory ai_project
```

Then visit `http://localhost:8000`.

The app is designed for a phone-sized browser but also displays in a centered mobile frame on a larger screen. All data is fictional prototype data, and the digital pass cannot be used for stadium entry.
