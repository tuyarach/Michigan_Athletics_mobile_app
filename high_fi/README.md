# Michigan Premier — Iteration 2

This is the simplified second iteration of the Michigan Premier mobile prototype. It takes a quieter, more exclusive direction: generous space, a dark Michigan-blue atmosphere, glass-like surfaces, restrained maize accents, and only the information a member needs in the moment.

It includes switchable home-screen passes for Gerald, Alex, and Morgan; a swipeable full-screen digital ticket drawer with QR codes; direct routes to a seat or pregame field access; step-free route preference; and a stadium map.

## Run the app

Open `index.html` in a browser, or serve this directory locally:

```bash
python3 -m http.server 8000 --directory iteration_2
```

Then visit `http://localhost:8000`.

The app is designed for a phone-sized browser but also displays in a centered mobile frame on a larger screen. All data is fictional prototype data, and the digital pass cannot be used for stadium entry.
